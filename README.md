# scos-bp-firmware

This is a repository for the firmware (FPGA and Embedded CPU)
for the SCOS blood pressure project.

|                           |                                                      |
|---------------------------|------------------------------------------------------|
| `Ariane_Code`             | simulation code in Matlab as used by Bernhard        |
| `mira_test`               | Bernhard's FPGA code for testing on Crosslink-NX EVB |
| `pi_hat_test/`            | Folder with firmware for custom Pi Hat board         |
| `pi_hat_test/pi_hat_uart` | UART-controlled power/clock test                     |
| `pi_hat_test/pi_hat_mira` | BZ firmware with power/clock control                 |
|                           |                                                      |
